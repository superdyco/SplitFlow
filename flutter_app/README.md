# 簡單分帳

「簡單分帳」是一款適合旅行、聚餐、合租與團體活動使用的分帳工具。

每位成員都可以記錄支出，系統會自動整理誰先付款、每個人應負擔多少，以及最後應該互相支付的金額，讓共同帳務更清楚。

## 產品特色

- 建立旅行、聚餐或其他共同分帳任務
- 邀請朋友加入並共同記帳
- 支援平均分攤與自訂分攤金額
- 支援多種幣別與匯率換算
- 自動計算每位成員的應收、應付金額
- 記錄付款與收款確認
- 依日期、分類與成員查看支出
- 可替支出加入地點與地圖資訊
- 可拍照或從相簿加入收據
- 保留結算紀錄，方便日後查詢
- 支援任務封存與成員權限管理
- 新增支出時通知其他任務成員

## 使用環境

### 網頁版

可使用電腦、平板或手機的現代瀏覽器開啟，適合建立任務、整理帳務及查看完整資料。

### Android App

目前可在 Android 手機使用，適合旅途中快速記帳、拍攝收據、搜尋地點及接收支出通知。

### iPhone／iPad

iOS 版本正在準備中，主要功能會與 Android App 共用。完成 Apple 簽章、地圖及推播設定並通過實機測試後即可提供使用。

## 跨裝置同步

網頁版與手機 App 使用同一組帳號及資料。只要登入相同帳號，就能在不同裝置查看自己的任務；共同任務中的新支出與結算資料也會同步更新。

例如，你可以在網頁版建立「曼谷之旅」，同行成員在手機 App 加入後，大家就能一起記帳並接收新支出通知。
