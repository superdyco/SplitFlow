# 簡單分帳

「簡單分帳」是一款適合旅行、聚餐、合租與團體活動使用的共同記帳工具。

成員可以一起記錄支出，系統會自動整理每個人的分攤金額、應收應付與付款狀態，減少人工計算及反覆核對帳目的麻煩。

## 產品特色

### 記帳

- 建立不同的旅行、聚餐或共同生活帳本
- 透過邀請連結加入任務並與朋友共同記帳
- 依日期與分類整理支出，並顯示消費分類統計
- 替支出加入地點、地圖、備註與當天天氣
- 拍照或從相簿加入收據
- 在手機 App 用語音輸入支出名稱

### 分攤與結算

- 支援平均分攤及自訂每位成員的分攤金額
- 支援多種幣別，記帳當下換算並保留匯率
- 自動計算成員之間的應收、應付金額，並算出最少的轉帳筆數
- 記錄付款，並由收款人確認
- 保存結算紀錄，方便日後查詢

### 成員

- 管理成員權限，區分擁有者、管理員與一般成員
- 可替沒有帳號的家人朋友建立成員，一起參與分攤
- 新增支出時通知其他任務成員
- 支援多種登入方式，網頁版與手機 App 共用相同帳號及資料

### 旅費報告

- 旅程結束後可產生公開的旅費報告，用連結分享給沒有加入的人
- 報告包含行程時間軸、消費分類、造訪地點與地圖
- 可選擇是否讓報告出現在探索頁，也可以隨時撤銷分享
- 看到喜歡的公開報告可以收藏起來

### 其他

- 支援離線瀏覽已載入的資料，回到連線後自動同步
- 已完成的任務可以封存保存，仍可查詢但不再變動

## 使用環境

### 網頁版

支援電腦、平板及手機的現代瀏覽器，適合建立任務、邀請成員、整理帳務及查看完整資料。

### Android App

目前可在 Android 手機使用，適合旅途中快速新增支出、拍攝收據、搜尋地點及接收成員通知。

### iPhone／iPad

iOS 版本正在準備中。主要分帳功能已與 Android 共用，完成 Apple 簽章、地圖、推播設定及實機測試後即可提供使用。

## 跨裝置使用

網頁版與手機 App 的資料會同步更新。使用者可以在電腦建立任務，再使用手機隨時新增支出或查看結算結果。

同一個共同任務中的成員可以使用不同裝置及不同帳號參與。例如在網頁版新增「曼谷之旅」的支出後，已加入任務的手機成員可以同步看到資料並收到通知。
